# Challenge 1: Reverse a String

## Difficulty: Easy | Points: 50 | Topic: Memory & STL

### Problem Statement
Write a C++ program that reads a string from standard input and prints the string reversed to standard output.

### Constraints
- Input string length: 1 <= length <= 1000
- Characters may include alphanumeric and punctuation.

### Examples
#### Example 1:
- Input: `hello`
- Output: `olleh`

#### Example 2:
- Input: `antigravity`
- Output: `ytivargitna`
