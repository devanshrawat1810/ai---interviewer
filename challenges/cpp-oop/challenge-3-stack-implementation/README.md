# Challenge 3: Stack Class Implementation

## Difficulty: Medium | Points: 100 | Topic: Classes & Objects (Encapsulation)

### Problem Statement
Implement a custom integer Stack class using OOP principles that supports operations:
- `push X`: Pushes integer X onto the stack.
- `pop`: Pops the top element and prints it. If empty, prints `EMPTY`.
- `peek`: Prints the top element without removing it. If empty, prints `EMPTY`.

### Input Format
First line: integer N (number of operations).
Following N lines: command string.

### Output Format
Print the result of each `pop` and `peek` command on a new line.
