# Challenge 4: Binary Search

## Difficulty: Medium | Points: 100 | Topic: Algorithms & STL

### Problem Statement
Given a sorted array of N integers and a target value T, use binary search to locate the 0-based index of T. If T is not found, print -1.

### Input Format
- Line 1: N and T (space-separated integers).
- Line 2: N sorted space-separated integers.

### Output Format
- Print the 0-based index or -1.
