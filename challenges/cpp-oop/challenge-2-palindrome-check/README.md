# Challenge 2: Palindrome String Check

## Difficulty: Easy | Points: 50 | Topic: Classes & Objects

### Problem Statement
Given a single string from standard input, determine whether the string reads the same backwards and forwards (case-sensitive). Print `YES` if it is a palindrome, and `NO` otherwise.

### Constraints
- 1 <= length <= 500

### Examples
#### Example 1:
- Input: `radar`
- Output: `YES`

#### Example 2:
- Input: `interview`
- Output: `NO`
